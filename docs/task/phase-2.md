# 第二阶段任务清单

## 1. 阶段目标

第二阶段目标是完善素材资产闭环，建立可检索、可分析、可人工修正的素材库。

完成后的最小闭环：

```text
用户选择产品
上传或登记人工清洗后的 clean shot
标注素材类型和基础人工信息
服务端探测视频技术信息
worker 抽帧并生成分析任务
Model Gateway 调用 VLM 或 mock provider
写入素材结构化 tags
前端可查看、筛选、修正素材标签
系统可按产品、卖点、素材类型、标签检索素材
```

第二阶段不直接追求完整 LLM 编排和真实成片渲染，重点是让后续编排有可靠的素材数据基础。
