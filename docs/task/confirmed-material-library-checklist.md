# 已确认任务清单：素材预处理与素材库边界

本文档只记录当前已经确认、不再继续讨论的约束与执行项。
它不替代 [system-overview.md](../system-overview.md) 的设计文档，而是把最近已经定下来的结论拆成可勾选任务。

## 1. 已确认规则

- [ ] 原始视频和预处理中的临时片段不进入服务端素材库
- [ ] 只有用户确认提交后的 clean shot 才能进入服务端素材库
- [ ] 客户端必须存在独立的“预处理工作区”
- [ ] 服务端素材库只保存正式资产，不保存处理中间态
- [ ] 服务端只识别正式素材库对象，不识别待处理工作区对象
- [ ] 未入库对象对服务端不可见，服务端不得直接读取、分析、调度或创建处理任务
- [ ] 服务端素材对象的基础单元仍然是 clean shot / `shot`
- [ ] `talking_head` 与 `visual_only` 必须在提交前明确标注
- [ ] `talking_head` 素材允许在提交前补充或导入口播转写
- [ ] `待提交` 的定义明确为：客户端工作区内的人工处理、`ffprobe`、抽帧、VLM 及必要补充信息都已完成，但尚未正式提交入库
- [ ] VLM 标准输入先固定为 3 帧
- [ ] 3 帧策略固定为前 / 中 / 后
- [ ] 具体抽帧位置固定为时长的 `10%` / `50%` / `90%`
- [ ] 当前不把“卖点强映射检索”作为海量素材主路径
- [ ] 海量素材主路径应依赖结构化标签、开放语义描述和后续向量召回

## 2. 客户端预处理工作区

- [ ] 支持用户批量选择原始视频文件
- [ ] 支持展示待处理原始视频列表
- [ ] 支持从待处理列表打开任意一条视频进入预处理窗口
- [ ] 预处理窗口内支持上一条 / 下一条切换
- [ ] 支持设置 clean shot 裁切起点
- [ ] 支持设置 clean shot 裁切终点
- [ ] 支持从单个原始视频导出一个或多个 clean shot
- [ ] 支持在预处理阶段标注素材类型：`visual_only` / `talking_head`
- [ ] 支持 `talking_head` 素材录入或导入带时间轴的转写文本
- [ ] 支持将未提交的预处理结果保留在客户端本地工作区
- [ ] 支持“仅保存，不提交入库”
- [ ] “仅保存”后的结果仍停留在客户端本地工作区
- [ ] 明确本地预处理工作区状态流：`待处理 -> 本地已保存 -> 待提交 -> 已入库`
- [ ] 支持对整个本地预处理工作区执行“清空”
- [ ] “清空”作用于工作区内的 `待处理`、`本地已保存`、`待提交` 项
- [ ] “清空”后本地工作区回到空工作区状态
- [ ] “清空”不影响已入库素材
- [ ] 支持用户明确执行“提交入库”
- [ ] 未提交的 clean shot 不生成服务端资产记录

## 3. 提交入库边界

- [ ] 定义客户端提交 clean shot 的元数据结构
- [ ] 提交元数据必须包含 `product_id`
- [ ] 提交元数据必须包含 `source_type`
- [ ] 提交元数据必须包含 clean shot 的基础文件信息
- [ ] `talking_head` 提交时允许携带转写结果
- [ ] 服务端收到提交后才创建正式 `asset`
- [ ] 正式提交动作只负责写入已经处理完成的 clean shot 与元数据
- [ ] 提交成功后客户端本地工作区状态更新为“已入库”
- [ ] 明确 `本地已保存` 到 `待提交` 的判定条件

## 4. 提交前分析完成条件

- [ ] clean shot 在客户端工作区内、正式提交前完成 `ffprobe` 媒体信息提取
- [ ] 提取并保存时长
- [ ] 提取并保存分辨率
- [ ] 提取并保存帧率
- [ ] 提取并保存视频编码与音频信息
- [ ] 在客户端工作区内、正式提交前按 `10% / 50% / 90%` 抽取 3 帧
- [ ] 将 3 帧作为 VLM 的标准输入
- [ ] VLM 回写画面描述
- [ ] VLM 回写景别
- [ ] VLM 回写运镜
- [ ] `talking_head` 在正式提交前补齐必要的转写信息

## 5. 素材库检索方向

- [ ] 将“结构化过滤”定义为素材库主检索入口之一
- [ ] 结构化过滤至少覆盖：产品、素材类型、时长、景别、是否有人声、可用状态
- [ ] 将“开放语义描述”定义为后续语义召回基础
- [ ] 后续向量化对象至少包含 `shot`
- [ ] 后续向量化对象为 `talking_head` 预留 `speech_segment`
- [ ] 明确高价值精选素材允许人工补充更强业务标签
- [ ] 明确海量普通素材不依赖人工逐条卖点映射

- [ ] 将“VLM 输入固定为前 / 中 / 后 3 帧”同步回系统设计文档
- [ ] 将“待提交 = 全部处理完成但尚未入库”同步回系统设计文档

## 7. 验收标准

- [ ] 用户可以在客户端批量选择原始视频
- [ ] 用户可以打开任意一条视频进入预处理窗口
- [ ] 用户可以在预处理窗口内切换上一条 / 下一条视频
- [ ] 用户可以在客户端完成 clean shot 预处理
- [ ] 用户可以仅保存预处理结果而不提交入库
- [ ] 用户可以清空整个本地预处理工作区
- [ ] 未提交前，服务端素材库中看不到该素材
- [ ] 未提交前，服务端也不会对该素材创建任何分析任务
- [ ] 清空本地预处理工作区后，服务端素材库中仍不会出现未提交素材
- [ ] 提交后，服务端成功创建正式 `asset`
- [ ] 用户进入 `待提交` 前，`ffprobe`、抽帧、VLM 等预处理分析已经完成
- [ ] 前端素材库中可以看到正式入库后的素材和分析结果
