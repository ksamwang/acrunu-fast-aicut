# 第三阶段任务清单

## 1. 阶段目标

第三阶段目标是打通从产品输入到可执行编排方案输出的主链路，建立“文案生成、配音生成、主叙事时间轴、素材召回、镜头装配、编排校验”的最小闭环。

完成后的最小闭环：

```text
用户选择产品和目标卖点
填写生成参数，如时长、风格、变体数量
系统生成脚本 variants
系统基于脚本生成最终口播/旁白配音
系统解析真实配音时间轴并写入 narration_segments
系统按 narration_segment 生成镜头需求
系统从素材库召回候选素材
LLM 在候选素材中完成 clip_segment 装配
系统输出可校验、可预览、可继续渲染的 edit_plan
```

第三阶段不直接追求最终成片导出，重点是让“编排结果”成为结构化、可验证、可重试的中间产物。

本文档只讨论实施任务，不重复展开 `docs/system-overview.md` 与 `docs/architecture.md` 中已经确认的设计结论。

## 13. 使用规则

- [ ] 只有在有代码、测试或真实运行验证支撑时，才勾选对应任务
- [ ] 如果某项能力只有接口或表结构，但没有闭环验证，不应标记完成
- [ ] 设计讨论以 [system-overview.md](../system-overview.md) 和 [architecture.md](../architecture.md) 为准
- [ ] 第三阶段任务清单只服务于当前系统设计，不额外引入未确认的新产品假设
